# ============================================================
# EQ 方案：ROG 臻世 + 拓品 DX5 II + 杨仕 7N 8股单晶铜 (4.4mm 平衡)
# 风格：日语流行 / 欧美流行
# 目标：宽声场 · 高分离度 · 人声贴耳
# 软件：Peace GUI (Equalizer APO)
# ============================================================
#
# 使用方法：
#   1. 打开 Peace，点击左上角"导入"，选择此文件
#   2. 或手动按下方参数逐条输入
#   3. 建议开启 Peace 的"限幅保护"（Limiter）防止过载
#
# Preamp（前置增益）：-4.0 dB  ← 必须设置，防止削波
# ============================================================

Preamp: -4.0 dB

# --- 低频段：收紧底噪、保留下潜 ---
# ROG 游戏耳机中频低段容易堆积，单晶铜线自带温润感，需适当削减中低频

Filter  1: ON PK Fc    60 Hz  Gain  +3.5 dB  Q 0.71
# 60Hz ↑  增强次低频下潜，流行音乐的鼓底和贝斯厚度

Filter  2: ON PK Fc   120 Hz  Gain  -3.0 dB  Q 1.00
# 120Hz ↓  收紧中低频膨胀（游戏调音的通病），还原鼓击清晰度

Filter  3: ON PK Fc   250 Hz  Gain  -2.5 dB  Q 1.20
# 250Hz ↓  清除浑浊感，提升乐器分离度，让声场"透气"

# --- 中频段：拓展声场宽度，避免挤压 ---

Filter  4: ON PK Fc   500 Hz  Gain  -1.5 dB  Q 1.50
# 500Hz ↓  微降，减少"箱声"，声场向外推

Filter  5: ON PK Fc  1000 Hz  Gain  -1.0 dB  Q 2.00
# 1kHz ↓   略微后推，增加纵深感，人声不会太"顶"

# --- 人声关键段：贴耳感核心 ---

Filter  6: ON PK Fc  2500 Hz  Gain  +3.0 dB  Q 1.50
# 2.5kHz ↑  人声齿音前的温暖段，日语女声、欧美流行主唱拉近感关键

Filter  7: ON PK Fc  3500 Hz  Gain  +2.0 dB  Q 2.00
# 3.5kHz ↑  人声质感和明亮度，配合 2.5kHz 双频提升贴耳感

# --- 高频段：空气感 + 乐器分离 ---

Filter  8: ON PK Fc  5000 Hz  Gain  +1.5 dB  Q 2.00
# 5kHz ↑   吉他拨弦、钢琴泛音，提升乐器立体感

Filter  9: ON PK Fc  8000 Hz  Gain  +2.5 dB  Q 1.50
# 8kHz ↑   齿音区上沿，分离度核心频段，镲片和弦乐清晰度

Filter 10: ON PK Fc 12000 Hz  Gain  +2.0 dB  Q 1.20
# 12kHz ↑  高频延伸，空气感，声场"天花板"拔高

Filter 11: ON PK Fc 16000 Hz  Gain  +1.0 dB  Q 1.00
# 16kHz ↑  超高频微提，录音室空气感（过于敏感者可关闭）

# ============================================================
# 调音逻辑说明
# ============================================================
#
# 【声场大】
#   → 削减 120-500Hz 的中低频堆积 = 声场向横向扩展
#   → 提升 8-16kHz = 声场纵深感和"天花板"
#
# 【乐器分离度高】
#   → 250Hz 和 500Hz 下降 = 消除频段互相遮蔽（masking）
#   → 5kHz/8kHz 提升 = 各乐器轮廓更清晰
#
# 【人声贴耳】
#   → 2500Hz + 3500Hz 双重提升 = 人声向前、向近推
#   → 不过度拉高 4kHz 以上以避免刺耳
#
# 【单晶铜线补偿】
#   → 单晶铜线自带中低频温润感，因此 120-250Hz 削减幅度比普通线略大
#
# 【DX5 II 特性】
#   → 拓品 DX5 II 本身底噪极低、输出干净，EQ 空间充裕，Preamp -4dB 足够安全
#
# ============================================================
# 可选微调方向
# ============================================================
#
# 如果人声还不够近：  2500Hz 再 +0.5~1.0 dB
# 如果高频有点刺耳：  8000Hz 降 0.5~1.0 dB，或 5000Hz 降 0.5dB
# 如果低频不够冲：    60Hz 再 +1.0 dB，或 120Hz 削减量减半
# 如果声场还想更宽：  500Hz 再 -0.5 dB
# 如果听久了疲劳：    12kHz 和 16kHz 均降 0.5~1.0 dB
#
# ============================================================
